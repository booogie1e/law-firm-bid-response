# 律师事务所投标响应文件 Skill

这是一套用于编制、修订和核验律师事务所投标响应文件的 Codex skill。它帮助助手对照招标文件、用户最新底稿和证明材料，处理资格审查、商务标、技术标、财务数据及索引页码。

## 使用原则

- 以招标文件要求和用户最新修改稿为准；有指定模板就使用模板。
- 只填写有证据支持的事实，不编造团队、报价、业绩或资格。
- 缺少依据的实际填报字段可留空并高亮，缺件和适配风险单独列明。
- 审计数字对照原报表独立复算；附件按招标要求完整保留。
- 索引页码以最终使用的软件生成的定版文件核验，不能用其他软件的页序代替。

## 文件

| 文件 | 用途 |
| --- | --- |
| `SKILL.md` | 核心规则和触发说明 |
| `references/workflow.md` | 从接收材料到交付的工作流 |
| `references/page-index-validation.md` | 页码索引核验方法 |
| `references/common-failures.md` | 常见失误及处理方法 |

## 安装和调用

把整个 `law-firm-bid-response` 文件夹放入 Codex 的个人 skills 目录 `~/.codex/skills/`。随后在新任务中提及 `$law-firm-bid-response`，并提供招标文件、最新底稿和已有证明材料。说明最终提交格式、使用的编辑软件及需要交付的文件。

本仓库只包含通用方法，不包含任何客户标书、裁判文书、审计报告或其他证明材料。使用者须自行核查每个项目的招标要求与事实证据。
