# 可复用的投标文件工作流

## 1. 接收与定版

- 保存招标文件、用户最新底稿、历史标书、证明材料的来源文件；记录文件版本、日期、项目名称及截止时间。用户给出新定稿时，把它作为后续核对的基准，之前的“终稿”不能自动沿用。
- 比较最新底稿与上一版的正文、表格单元格、图片数量与内容、签章用语、段落间距、分节和附件顺序。保留用户亲自调整的版面；不要为了省页数擅自压缩模板或加入重复图片标题。
- 用招标文件原文建立“条款—应答位置—证明材料—核查结论—缺口”表。资格门槛、评分项、报价、技术方案、签章分别列出。

## 2. 证据核验

| 证据类型 | 至少核对 |
| --- | --- |
| 执业许可证、年检 | 投标主体是总所或分所、统一社会信用代码、负责人、发证及年度考核记录；新文件替换旧文件。 |
| 律师团队 | 本项目名单、最低人数、每人执业证和年检；不得把旧标书成员直接当作本项目成员。 |
| 业绩与胜诉案例 | 金融机构是否为原告、被告是否为招标要求的借款人或保证人、标的金额、立案年份、案由、裁判结果、律师姓名及总分所限制。逐条判断资格门槛与不同评分项。 |
| 财务与税社保 | 审计报告年度、正文及三表是否齐全；财务数字取自正确年度与列；税社保所属期、缴纳主体、连续或任意月数是否满足招标要求。 |
| 三网站信用记录 | 查询主体、网址、查询日期、结果是否同页可见；分跨页时保留两页；区分投标人自查和代理机构最终查询。 |

先核对提交义务。若招标文件明确由代理机构开标当日查询，网页材料不因用户提供过就必须附入；最新底稿改成一句说明时，不再自动补回截图。信息不足时留空或写入独立缺件清单；不得把未经证明的案例表述为“符合资格”。对用户提供但不完全适配的证据，按用户指定位置处理，同时清楚报告差距。

## 3. 编写与排版

- 先用招标文件给出的表格和格式。自拟章节遵从用户底稿的中文字体、标题级别、行距、页边距及签章方式。
- 把采购要求转换成投标人第一人称的完整承诺书，逐项覆盖实质内容，避免保留“应承诺”“需提供”等招标指令。
- 技术方案按本项目服务对象、业务范围、履约节点和验收要求写，区分律所可控制的工作时限与法院程序时间。不借用其他项目的境外清盘等不同业务条款。
- 只标黄真正缺少内容的姓名、报价、日期、证明材料位置等字段。标黄前检查它是不是标签内的排版空格、已有文字的说明标题或表格格式。
- 审计报告和裁判文书优先保留原始页面图像及页码；裁判文书按招标要求提供关键页或全文。附件顺序与索引一致。

## 4. 校核与交付

1. 用独立计算核验财务数字和金额、比例、年限等条件；对照原始证明页。
2. 用用户最终使用的软件导出 PDF，目视检查封面、索引、承诺函、表格、图片首末页以及章节交界。替代排版软件的 PDF 只用于初查错字、图片缺失和明显空白页，不能据此认定 Word 页码。
3. 按 [page-index-validation.md](page-index-validation.md) 记录每一项的实际响应位置、附件范围和显示页码；把“有响应位置”和“证明是否足够”分开。若只有 DOCX 或替代软件的 PDF，明确页码尚未验证，取得 Word 原生导出或用户确认后再定版。
4. 每次增加、删除附件或调整行距后，重新导出并复核两张索引以及附件首末页。确认图像页不是被误判的空白页，且未出现“待核实”“需确认”等内部提示文字或误标黄。
5. 按用户要求交付文件或仅提供核对信息；缺件和资格风险直接说明。不要为了替用户“补全”而恢复其最新版本已删除的材料。
