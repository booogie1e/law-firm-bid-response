# 常见失误与处理方法

本文件只记录可复用的做法。任何历史项目的姓名、数字、案例和证明材料都不能自动用于新项目。

| 常见失误 | 处理方法 |
| --- | --- |
| 用旧版覆盖用户刚修改的底稿 | 先逐项比较新旧稿，只修改用户要求的部分，保留其表格、签章、附件和版面调整。 |
| 把历史标书的团队、报价或不同业务方案直接沿用 | 历史标书只作格式和经核实的通用资料参考；本项目事实须由本项目证据支持。 |
| 有模板仍自拟，或把评审条款原样粘成承诺函 | 优先使用招标模板；自拟承诺函采用投标人第一人称，逐项覆盖要求并核对签章。 |
| 证据放进索引便认定资格满足 | 分别核查页码位置和证据适配性。案例须逐项核对当事人身份、案由、金额、年度、代理律师及裁判结果。 |
| 财务表仅复制上一稿数字 | 对照审计报告原页确认年度和报表列，独立重算合计及比率；若要求全文，逐页保留报告。 |
| 收到材料后自动附入 | 先确认招标文件是否要求投标人提交，以及用户最新稿是否保留该材料。由采购方或代理机构查询的事项按招标要求处理。 |
| 把标签中的排版空格标黄 | 只高亮真正待填的字段；逐处检查姓名、电话、年龄等标签与已填内容。 |
| 把扫描页当作空白页删掉 | 对无可提取文字的图片页目视检查；删除真正空白页时复核前后附件的首末页。 |
| 转换软件导致图片或特殊图形缺失 | 对照原始文件检查图像、查询条件、结果和时间；必要时用原始证明页替换失真的转换页。 |
| 签章行单独落在一页 | 调整局部段前段后距和分页设置，复核正文完整、模板格式及签章位置。 |
| 可选技术章节只剩标题或空白页 | 按招标要求和用户选择处理可选内容，删除无内容的孤立标题及其空白页。 |
| 用另一排版软件推算索引页码 | 取得用户实际定版软件导出的 PDF 或其确认的页面证据，以最终显示页码逐项核验。任何内容变动后重新核对。 |
| 旧静态页码与自动页码并存 | 检查页脚字段，统一页码表现后再制作索引。 |

用户只索取页码、缺件清单等具体信息时，直接交付该信息。无法依据定版文件核准页码时，说明核验依据缺口，不给出猜测数字。
